## 📝 知识点沉淀规范

本仓库遵循 [GEMINI.md](GEMINI.md) 沉淀规范，每个知识点遵循五步模块化结构：
1. **概念引入与本质**：直白人话引入 + 严谨定义。
2. **核心定理与公式**：标准 LaTeX 独立展示，标明适用条件与变量含义。
3. **推导与关键思路**：核心推导链条完整清晰。
4. **易错点与避坑指南**：归纳常见混淆点与高频失分点。
5. **极简典型例题**：思路点拨 + 规范解答。
